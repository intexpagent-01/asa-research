# Governance

## Project overview

Pacific Aid Signal is an open-source aid intelligence tool for 14 Pacific island countries. It monitors IATI aid transactions, World Bank projects, DFAT procurement pipeline, and NZ MFAT tenders, refreshing every 12 hours with automated data quality corrections.

## Ownership and authority

The project is built and maintained by **Asa**, an autonomous AI agent running on Claude (Anthropic). Asa operates under a charter set by a human **Operator** who:

- Sets the strategic direction and hard rules
- Reviews and can revoke any publication permission
- Approves all external communications and account actions
- Controls infrastructure (domain registration, hosting accounts, API credentials)
- Retains final authority over all project decisions

The Operator is the legal owner of the infrastructure: the GitHub repository, the domain (pacificaidsignal.org), and the Cloudflare account hosting the Ask box endpoint.

## Decision-making

- **Technical decisions** (data pipeline, rendering, site structure) are made by Asa within the charter's boundaries.
- **External communications** (listing on platforms, contacting organisations, public posts) require explicit Operator approval with a recorded proposal and decision.
- **Spending** requires a concrete proposal to the Operator specifying purpose, amount, provider, risks, and review mechanism.
- **Content publication** follows the charter: Asa publishes autonomously to the approved site; the Operator can see everything and revoke permissions.

Pacific Development Intelligence

Give your AI assistant live development data for 14 Pacific island countries. Not a chatbot — a data connection that makes Claude, Copilot, or any MCP-compatible assistant genuinely useful for development work.

Why this is different from just asking Claude or ChatGPT

If you ask an AI assistant about Pacific aid today, it answers from its training data — months or years old, with no access to current figures. It will give you plausible-sounding paragraphs, but the numbers are either outdated, vague, or fabricated.

This MCP server connects your assistant to live data, refreshed every 12 hours. The difference is concrete:

Without the server

“What’s the aid picture in Fiji?”

  • General paragraphs about Fiji’s development
  • Mentions DFAT and JICA as “key donors”
  • No specific disbursement figures
  • Cannot tell you what changed this week
  • May hallucinate statistics
With the server

“What’s the aid picture in Fiji?”

  • $43.7M disbursed in the last 90 days
  • 11 active funders — led by UNDP, EU, UNICEF
  • Sector breakdown, data freshness per funder
  • Which funders went quiet, which are new
  • Every number traceable to source
Without the server

“What DFAT procurements are coming up in the Pacific?”

  • “I don’t have access to current procurement data”
  • Suggests checking dfat.gov.au manually
  • May recall programs from its training data
With the server

“What DFAT procurements are coming up in the Pacific?”

  • 30 pipeline items as at 9 October 2026
  • Which are in market, planned, or closed
  • Program names, countries, timing, approach
  • Recent business notifications with dates
Without the server

“What do evaluations say about water supply projects in the Pacific?”

  • General advice based on training data
  • May reference well-known evaluations
  • Cannot search a structured evidence base
With the server

“What do evaluations say about water supply projects in the Pacific?”

  • Searches 3,043 lessons from 991 World Bank evaluations
  • Filters by topic, country, outcome rating
  • Returns specific findings from specific projects
  • Distinguishes successful from unsuccessful projects

Sample: what a conversation looks like

You: “Compare Fiji and Solomon Islands — who are the main funders and how do aid volumes differ?”

Claude calls compare_countries and returns a structured comparison:

  • Fiji: $43.7M in the last 90 days from 11 funders. Led by UNDP ($14.7M), EU ($12.8M), UNICEF ($12.8M)
  • Solomon Islands: $11.4M from 10 funders. Led by ADB, NZ MFAT, UNDP

Claude can then follow up: “DFAT is the largest funder on record in both countries but has published no data dated after June 2025 — a 15-month gap. So the 90-day figures understate Australia’s actual presence.”

You: “Search for any activities related to climate adaptation in Tonga”

Claude calls search_activities with query “climate” filtered to Tonga, and returns matching IATI activities with their funder, spending, dates, and status. No manual searching, no portal navigation, no data cleaning.

You: “I’m designing a rural water supply project in a small island state. What does the evidence say about sustainability?”

Claude calls search_lessons with “water supply” and returns specific findings from evaluated projects — what worked (e.g. “combining infrastructure with institutional strengthening doubled sustainability rates”), what failed, and why. Each lesson links to a specific project evaluation, not training-data generalisations.

Eight tools, one data connection

get_country_summary

Aid summary for one country: disbursements, funders, sectors, data freshness, World Bank projects

get_regional_overview

All 14 countries at a glance: totals, rankings, pipeline summary

compare_countries

Side-by-side comparison of any two countries

get_dfat_pipeline

Australian aid procurement: in market, planned, closed. Filter by status or country

get_nz_tenders

New Zealand MFAT tenders for Pacific countries from GETS

search_activities

Search IATI activities by keyword, funder, or country across all 14 countries

search_lessons

3,043 lessons from 991 World Bank evaluations. Filter by topic, country, outcome

get_funder_profile

A funder’s Pacific portfolio: where they operate, how much, data freshness

Data sources

The server reads from four public sources, updated every 12 hours. About 70% of IATI transactions tagged to Pacific countries are actually for other countries — this server filters them out using recipient-country weighting.

  • IATI — international aid transactions from 40+ publishers
  • DFAT — Australian procurement pipeline and business notifications
  • NZ MFAT / GETS — New Zealand government tenders
  • World Bank — project data and 991 implementation completion reports

Try it out

Choose the AI tool you use. The quick setup takes about two minutes.

Claude Desktop Recommended

Quick setup (Mac/Linux):

  1. Install Node.js from nodejs.org if you don’t have it.
  2. Run these three commands in Terminal: 
    git clone https://github.com/intexpagent-01/asa-research.git
cd asa-research/mcp-server
bash setup.sh
    The setup script installs dependencies and configures Claude Desktop automatically.
  3. Restart Claude Desktop (quit and reopen). You should see a hammer icon in the chat — click it to confirm “pacific-dev-intel” appears with 8 tools.
  4. Ask a question. Try: “What’s the current aid picture in Fiji?”

Don’t have git? Download the ZIP from GitHub (green “Code” button → Download ZIP), unzip, open Terminal in the mcp-server folder, and run bash setup.sh.

Manual setup (Windows or if setup.sh doesn’t work)
  1. Clone and install: 
    git clone https://github.com/intexpagent-01/asa-research.git
cd asa-research/mcp-server
npm install
  2. Find the full path to server.js. In the terminal, run pwd (Mac/Linux) or (Get-Location).Path (Windows PowerShell).
  3. Open Claude Desktop settings. Settings (gear icon) → Developer → Edit Config.
  4. Add the server, replacing /full/path/to with your actual path: 
    {
  "mcpServers": {
    "pacific-dev-intel": {
      "command": "node",
      "args": ["/full/path/to/asa-research/mcp-server/server.js"]
    }
  }
}
    Windows: use forward slashes (C:/Users/...) or double backslashes.
  5. Restart Claude Desktop.

Claude Code (terminal)

  1. Install Node.js if you don’t have it — same as above.
  2. Clone and install: 
    git clone https://github.com/intexpagent-01/asa-research.git
cd asa-research/mcp-server
npm install
  3. Add the server to Claude Code: 
    claude mcp add pacific-dev-intel node /full/path/to/asa-research/mcp-server/server.js
  4. Start asking questions. Claude Code will use the tools automatically when relevant.

VS Code with GitHub Copilot Experimental

  1. Install Node.js and clone the repo as above.
  2. Open VS Code settings (Cmd/Ctrl+Shift+P → “Preferences: Open User Settings (JSON)”).
  3. Add MCP server config: 
    "mcp": {
  "servers": {
    "pacific-dev-intel": {
      "command": "node",
      "args": ["/full/path/to/asa-research/mcp-server/server.js"]
    }
  }
}
  4. In Copilot Chat, switch to Agent mode and ask a development question. Copilot should discover and use the tools.

MCP support in Copilot is still evolving. If tools don’t appear, check that you have the latest VS Code and Copilot extension.

ChatGPT

ChatGPT does not currently support MCP servers natively. If OpenAI adds MCP support, this server will work with it automatically — MCP is an open standard. In the meantime, you can use the tools listed above through Claude Desktop, Claude Code, or VS Code.

Why not just search the web?

Three reasons this server gives better answers than web search or browsing IATI portals:

  1. Data quality. About 70% of transactions tagged to Pacific countries in IATI are actually for other countries. Standard portals show you these uncorrected figures — for example, d-portal reports the US State Department as Tonga’s largest funder at $91 billion, when Tonga’s actual share is 0.005%. This server applies recipient-country weighting to every transaction.
  2. Cross-source synthesis. No single portal combines IATI transactions, DFAT procurement pipeline, NZ MFAT tenders, and World Bank evaluations. This server searches all four in one question.
  3. Structured answers. Instead of pointing you to a portal to browse, the server returns structured data your AI assistant can reason about, compare, and summarise.

How the data stays current

The server reads from snapshot files produced by the Pacific Aid Signal pipeline, which fetches fresh data every 12 hours. When you clone the repository, you get the latest snapshot. To update your local copy:

cd asa-research
git pull

The snapshot files are small (under 1 MB). A git pull takes seconds.
